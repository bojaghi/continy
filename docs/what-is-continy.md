# Continy는 무엇입니까?

워드프레스 플러그인이나 테마를 커스텀으로 개발하게 되면,
코드가 조금씩 커질수록 어떤 기능이 어떤 액션과 필터의 조합으로 구현되었는지 파악하기 어려워집니다.
또한 수많은 콜백들이 난무하고, 클래스별로 의존관계가 형성되는 등 코드의 유지보수와 확장이 어려워집니다.

Continy는 이러한 문제를 해결하기 위해 모듈을 지원합니다.
액션과 필터를 조합하여 어떤 기능을 선언하면 그것을 하나의 독립적인 모듈로서 관리될 수 있습니다.
이렇게 하면 여러 모듈들이 독립적으로 분리될 수 있어 보다 관리가 깔끔해집니다.

또한 Continy는 객체 관리도 지원합니다. 간단한 형태의 의존성 주입 또한 지원하여, 코드 작성시
객체간의 의존성 문제나 객체 생성 문제를 보다 쉽게 해결할 수 있습니다.

## Continy가 가진 기능

### 모듈 선언

워드프레스는 `do_action`, `apply_filters` 함수 호출에 의해 기능 확장을 합니다.
그리고 플러그인, 또는 테마는 `add_action`, `add_filter` 등의 함수를 통해 확장 기능을 구현하는데,
이 함수의 호출이 여기저기서 사용되어 섞이기 시작하면 왜 이것이 사용되는지 구분하기 어려워지기 시작합니다.

이를 막기 위해, 이 덩어리를 모듈별로 분리하여 관리합니다.
이렇게 하면 필요한 기능이 어떻게 구현되어 있는지 알아보기 용이해지며, 따라서 수정하기도 쉬워집니다.

### 객체 관리

객체를 매번 새로 생성하지 않고, 재활용을 가능하게 해 줍니다.
또한 클래스의 정확힌 이름을 이용하지 않고도 객체 생성을 가능하게 해 줍니다.

### 의존성 주입

클래스의 생성자나 메소드, 함수 호출시 필요한 파라미터를 Continy가 직접 채워 넣어 줍니다.
관리 중인 객체를 재사용할 수도, 새로운 객체를 생성하여 넣을 수도 있습니다.

#### 객체 생성

객체를 생성할 때, 생성자를 직접 호출하지 않고 Continy가 적절히 호출해 줍니다.
그러므로 클래스의 생성자 인수 변경이나 인터페이스 구현 변경에 유연하게 대응할 수 있습니다.

#### 함수 호출

객체 생성과 마찬가지로 함수 호출시에도 요구하는 인수 또한 Continy가 적절히 호출해 줍니다.
함수 시그니처 변경에 유연하게 대응할 수 있습니다.

### 콜백 문자열 해석

워드프레스의 특성상 콜백 함수가 여기저기 많이 사용됩니다. 이 때 매번 필요한 객체 생성 후 메소드 지정을 하는 것은 쉽지 않습니다.
콜백으로 사용할 클래스 메소드를 아래와 같은 방법으로 지정하면 Continy가 알아서 클래스 메소드로 바꿔 줍니다.

콜백 문자열은 `<id>@<method>` 형태의 문자열로 구성됩니다.

- `<id>`는 Continy가 인식할 수 있는 객체 식별자를 의미합니다.
- `<method>`는 메소드 이름을 말합니다.

예를 들어, 다음과 같은 클래스가 있다고 합니다.

```php
class My_Module implements Module {
    public function my_callback() {
    }
}
```

`My_Module::my_callback()` 메소드를 콜백으로 사용하는 경우, 원래라면 이렇게 해야 합니다.

```php
$instance = new My_Module();
add_action( 'hook', [$instance, 'my_callback'] );
```

이렇게 매번 모듈을 인스턴스화 시키고, 콜백을 지정하기 쉽지 않습니다.
그러나 Continy를 사용한다면 설정 배열에 아래처럼 이렇게 바인딩을 지정한 다음,

```php
$continy = Factory( array(
  'bindings' => array(
    'my_mod' => My_Module::class,
  )
) );
```

콜백 사용 시점에 다음처럼 콜백을 지정할 수 있습니다.

```php
add_action( 'hook', $continy->parse_callback( 'my_mod@my_callback' ) );
```

식별자 `my_mod`로 My_Module 클래스를 찾을 수 있고, 필요한 생성자 파라미터도 Continy가 알아서 해결해,
`[$instance, 'my_callback']`와 동일한 결과를 돌려줍니다.
